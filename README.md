# Ha-Py Virtuell

## Über das Projekt
Ha-Py Virtuell ist eine Augmented Reality (AR)-App, entwickelt von der Mobile-Etage GmbH, die es Nutzern ermöglicht, historische und kulturelle Inhalte interaktiv zu erleben. Das Projekt nutzt fortschrittliche AR-Technologie, um Bildung und Unterhaltung zu vereinen.

## Funktionen
- **AR-Touren**: Entdecken Sie virtuelle Darstellungen historischer Ereignisse an realen Orten.
- **Interaktive Inhalte**: Engagieren Sie sich durch Spiele und Quizze, die das Lernen fördern.
- **Multimedia-Galerien**: Zugriff auf reichhaltige Bild- und Videomaterialien.

## Schnellstart
Um mit dem Unity-Projekt "Ha-Py Virtuell" zu beginnen, folgen Sie diesen einfachen Schritten:

1. **Klonen Sie das Repository:**
```bash
git clone https://github.com/MobileEtage/Ha-Py-Virtuell
```
2. **Wechseln Sie in das Projektverzeichnis:**
```bash
cd Ha-Py-Virtuell
```

3. **Öffnen Sie das Projekt in Unity, indem Sie Unity Hub verwenden und das Verzeichnis Hameln-Pyrmont-Virtuell als Projekt auswählen.**
4. **Um das Projekt zu starten, drücken Sie in Unity auf den Play-Button.**
