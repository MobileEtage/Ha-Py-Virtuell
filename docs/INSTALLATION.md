# Installationsanleitung für Ha-Py Virtuell

Willkommen bei der Installationsanleitung für das Unity-Projekt "Ha-Py Virtuell". Diese Anleitung führt Sie durch die erforderlichen Schritte, um das Projekt auf Ihrem System einzurichten und auszuführen.

## Systemanforderungen

Bevor Sie beginnen, stellen Sie sicher, dass Ihr Computer die folgenden Anforderungen erfüllt:
- Betriebssystem: Windows 10, MacOS oder Linux
- [Unity Editor](https://unity.com/) (Version 2022.3.51f1 oder neuer)
- Git installiert, um das Projekt klonen zu können

## Das Projekt klonen

1. Öffnen Sie ein Terminal oder eine Eingabeaufforderung.
2. Führen Sie den folgenden Befehl aus, um das Repository zu klonen:
```bash
git clone https://github.com/MobileEtage/Ha-Py-Virtuell
3. Wechseln Sie in das Verzeichnis des geklonten Repositories:
```bash
cd Ha-Py-Virtuell

## Unity-Projekt öffnen
Nachdem Sie das Projekt erfolgreich geklont haben, folgen Sie diesen Schritten, um es in Unity zu öffnen:

1. Starten Sie den Unity Hub.
2. Klicken Sie auf 'Add' oder 'Hinzufügen' am oberen rechten Rand der Projekte-Seite.
3. Navigieren Sie zum Verzeichnis Ha-Py-Virtuell und wählen Sie den Projektordner aus.
4. Unity wird nun das Projekt importieren und einrichten. Dies kann je nach System einige Minuten dauern.

## Abhängigkeiten installieren
Das Projekt könnte spezifische Unity-Pakete oder Assets benötigen, die über den Unity Asset Store oder den Paketmanager installiert werden müssen:

1. Öffnen Sie das Projekt in Unity.
2. Navigieren Sie zu 'Window' > 'Package Manager'.
3. Überprüfen Sie, ob alle notwendigen Pakete aufgelistet und installiert sind. Installieren oder aktualisieren Sie bei Bedarf.

## Das Projekt starten
Um das Projekt auszuführen:

1. Wählen Sie in Unity die Hauptszene aus, die sich typischerweise im Verzeichnis Assets/Scenes befindet.
2. Drücken Sie den 'Play'-Button in Unity, um das Projekt im Editor zu starten.

## Probleme lösen
Falls Sie auf Probleme bei der Installation oder beim Ausführen des Projekts stoßen, überprüfen Sie die folgenden Punkte:
- Stellen Sie sicher, dass Sie die richtige Unity-Version verwenden.
- Überprüfen Sie, ob alle notwendigen Pakete und Abhängigkeiten korrekt installiert sind.
- Konsultieren Sie das README.md-Dokument für weitere Informationen oder besuchen Sie den Abschnitt 'Issues' im GitHub-Repository.

Vielen Dank, dass Sie sich für die Installation von Ha-Py Virtuell entschieden haben. Wir hoffen, dass Sie Spaß an der Nutzung und Entwicklung des Projekts haben werden.
